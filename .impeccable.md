## Design Context

- **Audience:** Potential collaborators, users, and technically curious visitors arriving from GitHub.
- **Use cases:** Understand what R. Teodoro contributes, scan a curated set of original public projects, compare public contribution activity, visit source code or a live artifact, and continue the conversation through GitHub.
- **Brand personality:** Exact, resourceful, restless. The visual language is a midnight field notebook with an amber signal: editorial rather than corporate, technical without terminal cosplay.
- **Public boundary:** Use only information already visible on the public `rteoo` GitHub profile and public repositories. Do not add data from non-public sources or infer contact or biographical details.
- **Statistics:** Contribution counts come only from public repository contributor lists and refer to authored commits on each default branch. Date every snapshot, exclude private totals, and distinguish the profile repository from project work.
- **Accessibility:** Semantic structure, visible keyboard focus, sufficient contrast, reduced-motion support, and responsive layouts from narrow mobile screens upward.

### Working model

- **Visual thesis:** An editorial contribution ledger on midnight navy, using warm amber to make real public work legible at a glance.
- **Content plan:** Identity and ranked contribution ledger; public project index; working principles; GitHub call to action.
- **Interaction thesis:** A staged hero entrance, proportional bars that resolve into place, and project/reveal transitions that preserve meaning without motion.
